# ThoughtCanvas

## Vision

ThoughtCanvas is an AI-first handwriting journal.

**Philosophy**

- Ink first.
- Structure later.
- AI understands afterwards.
- Offline first.
- User owns the data.

Inspired by:
- Concepts
- Diarium
- Obsidian
- NotebookLM

Long-term goal:
A personal knowledge system built around handwriting, structured documents, and AI.
