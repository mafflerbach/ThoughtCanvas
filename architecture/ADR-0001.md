# ADR-0001

## Architecture

Decision:
Use Kotlin Multiplatform for shared business logic where practical.

Reason:
Allows Android first while enabling future Desktop (Compose) and potential web support.

Data ownership:
Filesystem is the source of truth.
Database is an index.

AI:
Provider abstraction from day one.

Storage:
Vector ink is immutable.
Recognized text is a derived layer.
