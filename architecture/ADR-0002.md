# ADR-0002 — Android-only MVP with KMP-ready boundaries

## Status
Accepted

## Context
ADR-0001 called for Kotlin Multiplatform. AGENTS.md mandates Hilt and Room, both
Android-only. Shipping an Android tablet MVP quickly outweighs multi-platform
purity today.

## Decision
- The MVP targets Android only.
- Hilt for DI, Room for persistence remain in use.
- `:core:*` modules stay free of Compose and UI code so they can be refactored
  into a KMP `commonMain` source set later without touching feature modules.
- Public APIs of `:core:*` are expressed as plain Kotlin interfaces returning
  coroutines/flows to keep the KMP door open.

## Consequences
- Faster path to a usable app on the Xiaomi Pad and Boox Note 4C.
- Future KMP migration requires swapping Hilt → Koin and Room → SQLDelight in
  `:core:*` only, guided by a follow-up ADR.
