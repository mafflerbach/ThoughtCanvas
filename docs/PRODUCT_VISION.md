# Product Vision

ThoughtCanvas is not a note-taking app.

It is a document platform composed of blocks:

- Ink
- Markdown
- Images
- Audio
- PDFs
- AI annotations
- Tasks

AI should never overwrite handwriting.

Users explicitly select regions for handwriting recognition.

AI actions:
- Convert to Markdown
- Summarize
- Translate
- Rewrite
- Generate tags
- Link related notes
- Export to Obsidian
